## Run It Locally

1. Clone the repo and run `npm install`.
2. Get a free API key from Pixabay: https://pixabay.com/api/docs/
3. Create a file named `.env` in the project root with this line:

   `REACT_APP_PIXABAY_API_KEY=your_key_here`

4. Run `npm start`.
